📁 ОСНОВНЫЕ ФАЙЛЫ (ОБЯЗАТЕЛЬНО):

1. 🐍 main.py
   └─ Основной скрипт бота на Python
   └─ Размер: ~5 KB
   └─ Обработка команд, работа с БД

2. 🎨 app.html
   └─ Мини-приложение для просмотра видео
   └─ Размер: ~15 KB
   └─ Черно-белый дизайн, адаптивный

3. 👑 admin.html
   └─ Админ-панель для управления ботом
   └─ Размер: ~20 KB
   └─ Статистика, рассылка, управление

4. 📋 requirements.txt
   └─ Зависимости Python
   └─ Размер: 100 байт
   └─ aiogram, python-dotenv, aiohttp

5. ⚙ .env
   └─ Конфигурация (ВАЖНО: не загружай на GitHub!)
   └─ Размер: 200 байт
   └─ Токен, ID, URL

6. 📖 README.md
   └─ Полная документация проекта
   └─ Размер: ~10 KB
   └─ Инструкции, описание, FAQ

7. 📌 .gitignore
   └─ Исключения для Git
   └─ Размер: ~1 KB
   └─ Скрывает .env и БД

8. 🔧 config.example.py
   └─ Пример конфигурации с комментариями
   └─ Размер: ~2 KB
   └─ Для справки и локального использования

9. 🚀 Procfile
   └─ Конфиг для запуска на Bothost.ru
   └─ Размер: 25 байт
   └─ worker: python main.py

10. 📱 SETUP.md
    └─ Пошаговые инструкции для телефона
    └─ Размер: ~8 KB
    └─ От создания бота до запуска

═══════════════════════════════════════════

📊 СТАТИСТИКА:
- Всего файлов: 10

- Поддержка: Python 3.9+

═══════════════════════════════════════════

🚀 ПОРЯДОК ДЕЙСТВИЙ:

1. Создай папку проекта: my-cinema-bot

2. Копируй файлы в эту папку (В ТАКОМ ПОРЯДКЕ):
   ✓ main.py
   ✓ app.html
   ✓ admin.html
   ✓ requirements.txt
   ✓ .env (ВАЖНО: заполни свои данные!)
   ✓ README.md
   ✓ .gitignore
   ✓ config.example.py
   ✓ Procfile
   ✓ SETUP.md

3. Создай GitHub репо и загрузи все файлы
   (кроме .env - исключается через .gitignore)

4. На Bothost.ru подключи GitHub репо

5. Заполни Environment Variables:
   - BOT_TOKEN
   - ADMIN_ID
   - WEB_APP_URL

6. Нажми "Запустить" - всё готово! 🎉

🔑 ПОЛУЧЕНИЕ ДАННЫХ:

BOT_TOKEN:
- Откри @BotFather в Telegram
- Отправь /newbot
- Следуй инструкциям
- Скопируй токен

ADMIN_ID:
- Откри @userinfobot в Telegram
- Отправь сообщение
- Скопируй свой ID

WEB_APP_URL:
- После запуска на Bothost.ru
- Например: https://my-bot.bothost.ru
