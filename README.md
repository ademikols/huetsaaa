# 🎬 КИНОТЕАТР - Telegram бот для совместного просмотра видео

Telegram бот с мини-приложением для просмотра видео вместе с друзьями через ссылки YouTube, VK и RuTube.

## 🚀 Быстрый старт

### Шаг 1: Создаем бота в Telegram

1. Откри `@BotFather` в Telegram
2. Отправь `/newbot`
3. Придумай имя: `My Cinema Bot`
4. Придумай username: `my_cinema_bot`
5. **Скопируй токен** (будет похож на: `7842752682:AAHSxxxxxxxxxxxxxxxxxxxxxxxxxx`)

### Шаг 2: Получи свой ID

1. Напиши `@userinfobot` в Telegram
2. Скопируй свой ID

### Шаг 3: Заполни `.env` файл

```
BOT_TOKEN=7842752682:AAHSxxxxxxxxxxxxxxxxxxxxxxxxxx
ADMIN_ID=123456789
WEB_APP_URL=https://yourdomain.com
```

**Замени значения на свои!**

## 📤 Развертывание на Bothost.ru

### Способ 1: Через GitHub (РЕКОМЕНДУЕТСЯ)

1. **Создай репозиторий на GitHub:**
   - Откри https://github.com/new
   - Назови `my-cinema-bot`
   - Создай

2. **Загрузи файлы:**
   ```
   main.py
   app.html
   admin.html
   requirements.txt
   .env (БУДЕТ СКРЫТ)
   README.md
   ```

3. **На Bothost.ru:**
   - Регистрируемся на https://bothost.ru
   - Нажимаем "Создать бота"
   - Выбираем "Aiogram"
   - Вставляем ссылку репо: `https://github.com/YOUR_USERNAME/my-cinema-bot`
   - Заполняем переменные окружения:
     ```
     BOT_TOKEN = твой_токен
     ADMIN_ID = твой_id
     WEB_APP_URL = https://твой-домен.bothost.ru
     ```
   - Нажимаем "Запустить"

### Способ 2: Прямая загрузка файлов

1. На Bothost.ru выбираем "Загрузить файлы"
2. Загружаем все файлы по одному
3. Заполняем `.env` прямо на хостинге

## 📝 Что делает каждый файл

### `main.py`
- Основной скрипт бота
- Обработка команд
- Управление сессиями в БД SQLite
- Админ-панель в Telegram

**Команды:**
- `/start` - Начало
- `/admin` - Админ-панель (только для ADMIN_ID)

### `app.html`
Мини-приложение с функциями:
- 🎯 **СОЗДАТЬ** - Создать сессию с видео
- ✅ **ПРИСОЕДИНИТЬСЯ** - Присоединиться к сессии
- 📺 **СМОТРЕТЬ** - Просмотр видео

**Поддерживаемые источники:**
- YouTube (youtube.com, youtu.be)
- ВКонтакте (vk.com/video)
- RuTube (rutube.ru)

### `admin.html`
Админ-панель с функциями:
- 📊 Статистика (пользователи, сессии)
- 👥 Управление пользователями
- 🎬 Управление сессиями
- 📢 Массовая рассылка
- ⚙ Параметры бота

## 🔧 Установка локально (для тестирования)

### На ПК:

1. **Установи Python 3.9+:**
   - Скачай с python.org
   - При установке отметь "Add to PATH"

2. **Открой командную строку:**
   ```cmd
   cd путь-к-проекту
   ```

3. **Установи зависимости:**
   ```cmd
   pip install -r requirements.txt
   ```

4. **Запусти бота:**
   ```cmd
   python main.py
   ```

### На Телефоне (Termux):

1. **Установи Termux** из Google Play

2. **В Termux:**
   ```bash
   apt update && apt upgrade
   apt install python3 git
   pip install -r requirements.txt
   python3 main.py
   ```

## 🌐 Настройка веб-приложения

Bothost.ru генерирует URL для мини-приложения:

```
https://your-bot.bothost.ru/app.html
```

Убедись, что в `.env`:
```
WEB_APP_URL=https://your-bot.bothost.ru
```

## 💾 База данных

Бот использует **SQLite** (файл `movies.db`):

```sql
-- Таблица пользователей
users: user_id, username, created_at

-- Таблица сессий просмотра
sessions: id, user_id, link, created_at, status

-- Таблица администраторов
admins: user_id
```

База создается автоматически при первом запуске.

## 🐛 Решение проблем

### Бот не запускается
- Проверь токен в `.env`
- Убедись, что установлены зависимости
- Посмотри логи на Bothost.ru

### Мини-приложение не открывается
- Проверь WEB_APP_URL в `.env`
- Убедись, что сайт доступен
- Перезагрузи бота

### База данных не создается
- Проверь права доступа
- Убедись, что хостинг поддерживает SQLite
- Проверь размер хранилища
